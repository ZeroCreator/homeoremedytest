# 🔄 Синхронизация данных между устройствами

**HomeoRemedyTest** позволяет синхронизировать ваши карточки между разными устройствами, обеспечивая доступ к данным с компьютера, планшета или телефона.

## 🎯 Зачем нужна синхронизация?

- **Доступ с любого устройства** - учитесь дома на компьютере, повторяйте в транспорте на телефоне
- **Защита от потери данных** - если одно устройство сломается, данные будут на других
- **Совместная работа** - несколько пользователей могут работать с одними данными
- **Автоматическое обновление** - изменения на одном устройстве появляются на других

## 🔧 Как настроить синхронизацию

**Шаг 1: Подготовка Яндекс.Диска**

1. Убедитесь, что у вас есть аккаунт Яндекс
2. Получите OAuth-токен (см. раздел "Хранение данных")
3. Сохраните токен в безопасном месте

**Шаг 2: Настройка первого устройства**

1. Создайте файл `.env` с токеном Яндекс.Диска
2. Установите `STORAGE_MODE=hybrid`
3. Запустите приложение - данные автоматически загрузятся на Яндекс.Диск

**Шаг 3: Настройка других устройств**

1. Установите приложение на новое устройство
2. Добавьте тот же файл `.env` с тем же токеном
3. Запустите приложение - данные автоматически скачаются с Яндекс.Диска

## ⚙️ Как работает синхронизация

📱 **Пример работы с двумя устройствами:**

1. **Утром на компьютере** вы добавляете 10 новых карточек
2. Приложение сохраняет их только локально (не отправляет в облако)
3. **Днем в транспорте на телефоне** вы открываете приложение
4. Приложение работает с локальными данными (новых карточек нет)
5. Вечером на компьютере вы нажимаете "Синхронизировать на Яндекс.Диск"
6. 10 новых карточек загружаются на Яндекс.Диск
7. Утром на телефоне вы нажимаете "Загрузить с Яндекс.Диска"
8. Все 10 новых карточек загружаются на телефон

## 🔀 Алгоритм синхронизации

При каждом запуске приложение выполняет:

```plaintext
1. Загрузить локальные данные
2. Проверить доступность Яндекс.Диска
3. Если Яндекс.Диск доступен:
   a. Загрузить данные с Яндекс.Диска
   b. Сравнить версии файлов
   c. Если Яндекс.Диск новее:
      - Определить новые/измененные карточки
      - Объединить с локальными данными
      - Сохранить обновленные данные локально
   d. Если локальные данные новее:
      - Оставить как есть (не загружать на Яндекс.Диск)
4. Если Яндекс.Диск недоступен:
   - Работать только с локальными данными
5. Запись на Яндекс.Диск происходит ТОЛЬКО по кнопке "Синхронизировать"
```

## 🔄 Режимы синхронизации

| Режим | Когда использовать | Плюсы | Минусы |
|-------|-------------------|-------|--------|
| **Автоматическая** | Всегда (рекомендуется) | ✅ Все изменения сразу синхронизируются | ❌ Требует интернет-соединения |
| **По запросу** | При медленном интернете | ✅ Контроль над временем синхронизации | ❌ Риск потери несинхронизированных данных |
| **Только Wi-Fi** | При ограниченном мобильном трафике | ✅ Экономия мобильного трафика | ❌ Задержка синхронизации при отсутствии Wi-Fi |

## ⚠️ Решение конфликтов синхронизации

**Что такое конфликт синхронизации?**  
Это ситуация, когда одна и та же карточка была изменена на двух разных устройствах до их синхронизации.

**Как приложение решает конфликты:**

1. Определяется, какое изменение было последним (по времени изменения)
2. Последнее изменение считается приоритетным
3. Старая версия сохраняется в истории изменений
4. Вы можете просмотреть историю изменений в деталях карточки

## 📊 Мониторинг синхронизации

Вы можете отслеживать состояние синхронизации:

- **В разделе "Статус системы"** - общая информация о хранилищах
- **В разделе "Отладка хранилища"** - детальная техническая информация
- **В логах приложения** - подробный журнал всех операций синхронизации

## 🔐 Безопасность данных

Ваши данные защищены:

- **Шифрование соединения** - все данные передаются по HTTPS
- **OAuth-токены** - доступ только через авторизацию Яндекс
- **Локальное хранение** - чувствительные данные не покидают ваше устройство
- **Регулярные бэкапы** - защита от случайного удаления

## 💡 Советы по эффективной синхронизации

1. **Используйте одно устройство для основных изменений** - это минимизирует конфликты
2. **Создавайте бэкапы перед длительным отключением от интернета**
3. **Проверяйте статус синхронизации** при переключении между устройствами
4. **Используйте описательные имена для бэкапов** - это поможет при восстановлении
5. **Регулярно обновляйте OAuth-токен** - токены истекают через 1 год

## ❓ Частые вопросы о синхронизации

**Вопрос: Как часто происходит синхронизация?**<br>
**Ответ:** Чтение с Яндекс.Диска происходит при каждом запуске. Запись на Яндекс.Диск - только по нажатию кнопки "Синхронизировать".

**Вопрос: Что если я изменю данные без интернета?**<br>
**Ответ:** Изменения сохранятся локально. При появлении интернета вы можете отправить их на Яндекс.Диск через кнопку "Синхронизировать".

**Вопрос: Можно ли синхронизировать данные с другими сервисами кроме Яндекс.Диска?**<br>
**Ответ:** В текущей версии поддерживается только Яндекс.Диск. В будущих версиях планируется добавить другие сервисы.

**Вопрос: Сколько места нужно на Яндекс.Диске?**<br>
**Ответ:** Около 1 МБ на 1000 карточек + место для бэкапов. Обычно хватает бесплатного тарифа (10 ГБ).
