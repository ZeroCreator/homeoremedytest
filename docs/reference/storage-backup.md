# 🔐 Хранение данных и система бэкапов

**HomeoRemedyTest** использует продвинутую систему хранения данных с поддержкой синхронизации и автоматического резервного копирования.

## 📂 Режимы хранения данных

Приложение поддерживает три режима работы с данными:

### 🏠 Локальный режим
**Как работает:** Данные хранятся только на вашем устройстве в файле `test_cards.json`

✅ **Преимущества:**<br>
- Не требует интернета<br>
- Максимальная скорость работы<br>

❌ **Недостатки:**<br>
- Нет синхронизации между устройствами<br>
- Риск потери данных при сбое устройства<br>

### ☁️ Режим Яндекс.Диск
**Как работает:** Данные хранятся только на Яндекс.Диске

✅ **Преимущества:**<br>
- Доступ с любого устройства<br>
- Автоматическая синхронизация<br>

❌ **Недостатки:**<br>
- Требует постоянного интернет-соединения<br>
- Медленнее локального режима<br>

### 🤝 **Гибридный режим (рекомендуется)**
**Как работает:** Данные хранятся и локально, и на Яндекс.Диске

✅ **Преимущества:**<br
- Быстрая работа с локальной копией<br>
- Синхронизация между устройствами<br>
- Работа без интернета (с локальной копией)<br>
- Автоматическое объединение изменений<br>

⏱️ **Требует:** первоначальную настройку Яндекс.Диска

## 🔄 Как работает гибридная синхронизация

Гибридный режим работает по принципу **"только чтение из облака"**:

**При запуске приложения:**

1. Загружаются локальные данные
2. Проверяется Яндекс.Диск на наличие обновлений
3. Если данные на Яндекс.Диске новее - они загружаются
4. Если локальные данные новее - они остаются без изменений
5. **Данные НЕ загружаются на Яндекс.Диск автоматически**

**При сохранении изменений:**

1. Данные сохраняются только локально
2. **Данные НЕ отправляются на Яндекс.Диск автоматически**
3. Для отправки на Яндекс.Диск используйте кнопку "Синхронизировать"

**Ручная синхронизация:**

- **Кнопка "Синхронизировать на Яндекс.Диск"** - отправляет локальные данные в облако
- **Кнопка "Загрузить с Яндекс.Диска"** - заменяет локальные данные облачной версией
- Контроль над синхронизацией полностью в ваших руках

🎯 **Преимущества такого подхода**

- **Полный контроль** - вы решаете, когда синхронизировать
- **Безопасность** - случайные изменения не попадают в облако
- **Экономия трафика** - данные отправляются только по вашему желанию
- **Работа без интернета** - можно вносить изменения офлайн

## 💾 Система бэкапов

### Автоматические бэкапы
Приложение автоматически создает резервные копии:

🔄 **При значительных изменениях** (импорт, массовое редактирование)  
📅 **При запуске** (если включена опция)  
⚠️ **Перед опасными операциями** (восстановление, очистка данных)

### Ручное создание бэкапов
Вы можете в любой момент создать резервную копию:

1. Перейдите в раздел "Управление бэкапами"
2. Нажмите "Создать бэкап"
3. Укажите описание (необязательно)
4. Выберите где сохранить:<br>
    - 📁 **Локально** - только на вашем устройстве<br>
    - ☁️ **На Яндекс.Диске** - в облаке<br>
    - 🤝 **Везде** - и локально, и в облаке<br>

### Восстановление из бэкапа
Для восстановления данных:

1. Откройте раздел "Управление бэкапами"
2. Выберите нужный бэкап из списка
3. Нажмите "Восстановить"
4. Подтвердите операцию
5. Выберите куда восстановить (локально, на Яндекс.Диске или везде)

### Управление бэкапами
Вы можете:

📋 **Просматривать все бэкапы** - локальные и с Яндекс.Диска  
📊 **Сортировать** по дате, размеру или количеству карточек  
🗑️ **Удалять старые бэкапы** для экономии места  
🔍 **Просматривать информацию** о каждом бэкапе

## ⚙️ Настройка Яндекс.Диска

**1. Получение OAuth-токена**

1. Перейдите на [страницу разработчика Яндекс ID](https://yandex.ru/dev/id/)
2. Создайте новое приложение (тип "Веб-сервисы")
3. В настройках добавьте разрешение на доступ к Яндекс.Диску
4. Скопируйте OAuth-токен

**2. Настройка приложения**

1. Создайте файл `.env` в корневой папке приложения
2. Добавьте строку: `YANDEX_DISK_TOKEN=ваш_токен`
3. Перезапустите приложение

**Пример файла .env:**

```env
# Настройки приложения
SECRET_KEY=ваш_секретный_ключ
STORAGE_MODE=hybrid

# Настройки Яндекс.Диска
YANDEX_DISK_TOKEN=y0_Xxxxxxxxxxxxxxxxxxxxxxx
YANDEX_DISK_PATH=HomeoRemedyTest/data/test_cards.json
```

## 🔧 Настройка режима хранения

Режим хранения настраивается в файле `.env`:

| Режим | Значение в .env | Описание |
|-------|----------------|----------|
| `local` | `STORAGE_MODE=local` | Только локальное хранение |
| `yandex` | `STORAGE_MODE=yandex` | Только Яндекс.Диск |
| `hybrid` | `STORAGE_MODE=hybrid` | Гибридный режим (рекомендуется) |

## ⚠️ Устранение неполадок

**Проблема: Не работает синхронизация с Яндекс.Диском**

Возможные причины и решения:

1. **Неправильный токен:** Проверьте, что токен в файле .env верный и действителен
2. **Истек срок действия токена:** Токены Яндекс.Диска действительны 1 год
3. **Нет интернет-соединения:** Проверьте подключение к интернету
4. **Мало места на Яндекс.Диске:** Освободите место или увеличьте квоту
5. **Ошибки в пути файла:** Проверьте путь в YANDEX_DISK_PATH

**Проблема: Бэкапы не создаются/не восстанавливаются**

Решения:

1. **Проверьте права доступа:** У приложения должны быть права на запись в папку backups
2. **Проверьте настройки Яндекс.Диска:** Токен должен иметь права на запись
3. **Проверьте наличие места:** На диске должно быть достаточно свободного места

## 💡 Рекомендации по использованию

1. **Всегда используйте гибридный режим** - это защитит ваши данные
2. **Создавайте бэкапы перед важными изменениями**
3. **Храните хотя бы один бэкап на Яндекс.Диске**
4. **Периодически проверяйте состояние хранилища** в разделе "Статус системы"
5. **Обновляйте токен Яндекс.Диска раз в год**

> 💡 **Совет:** Регулярно проверяйте раздел "Статус системы" для мониторинга состояния хранилища и бэкапов.
