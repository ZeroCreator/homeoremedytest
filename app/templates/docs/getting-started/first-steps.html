Поздравляем с установкой HomeoRemedyTest! В этом руководстве вы познакомитесь с интерфейсом приложения и научитесь основным действиям.

🏠 Знакомство с интерфейсом

При первом открытии приложения вы увидите:

1. Верхняя панель

  • Логотип и название - кликните для перехода на главную
  • Главная - основная страница с карточками
  • Добавить вопрос - создание новой карточки
  • Переключатель режимов - между сеткой и стопкой
  • Меню действий (три точки) - дополнительные функции

2. Боковая панель слева

  • Поиск - быстрый поиск по карточкам
  • Темы - фильтр по категориям
  • Сложность - фильтр по уровню
  • Версии - фильтр по тестам
  • Статистика - информация о ваших карточках

3. Основная область

Здесь отображаются ваши карточки в выбранном режиме.

📝 Ваша первая карточка

Давайте создадим первую карточку вместе:

Шаг 1: Нажмите на кнопку "+"

В правом верхнем углу найдите кнопку с иконкой плюса и нажмите на нее.

Шаг 2: Заполните форму

Пример карточки по гомеопатии:

1. Тема: Растения (можно несколько через запятую: Растения, Жаропонижающие)

2. Вопрос: Какое гомеопатическое средство показано при сухости во рту и жажде?

3. Ответ: Bryonia (Переступень белый)

4. Объяснение: Показана при сухих слизистых, колющих болях, усиливающихся от малейшего движения, и сильной жажде холодных напитков.

5. Сложность: Легкий (выберите из списка)

6. Версия: Экзамен 1 (опционально)

Шаг 3: Нажмите "Сохранить вопрос"

Поздравляю! Вы создали свою первую карточку.

🔍 Поиск и фильтрация

Быстрый поиск

Введите в поле поиска слово "сухость" - вы увидите только что созданную карточку.

Фильтр по теме

В боковой панели найдите раздел "Темы" и нажмите на "Растения". Вы увидите все карточки по этой теме.

Фильтр по сложности

Нажмите на "Легкие" в разделе "Сложность" - вы увидите все карточки с легким уровнем.

👁️ Просмотр карточек

Режим сетки (по умолчанию)

Карточки отображаются в виде сетки. Чтобы увидеть ответ:

1. Найдите созданную карточку

2. Нажмите на кнопку "Показать ответ"

3. Ответ появится под вопросом

Режим стопки

Переключитесь в режим стопки, нажав на иконку с карточками вверху:

1. Видна одна карточка

2. Перетащите ее влево/вправо для смены

3. Используйте стрелки для навигации

📊 Просмотр статистики

В боковой панеле откройте раздел "Статистика":

  • Общее количество карточек
  • Количество по темам
  • Количество скрытых карточек

📤 Экспорт данных

Давайте сделаем резервную копию вашей первой карточки:

1. Нажмите на меню действий (три точки)

2. Выберите "Экспорт в Excel"

3. Файл скачается автоматически

Откройте файл в Excel - вы увидите все ваши карточки в табличном формате.

🎯 Практические задания

Для закрепления создайте еще несколько карточек:

Карточка 2:

  • Тема: Животные
  • Вопрос: Какой препарат изготавливается из яда пчелы?
  • Ответ: Apis mellifica
  • Сложность: Средний

Карточка 3:

  • Тема: Минералы
  • Вопрос: Калиум карбоникум показан при каких состояниях?
  • Ответ: Слабость, отеки, чувствительность к холоду
  • Сложность: Сложный

Карточка 4:

  • Тема: Нозоды
  • Вопрос: Что такое Tuberculinum?
  • Ответ: Нозод туберкулеза
  • Объяснение: Используется при наследственной предрасположенности к туберкулезу

💡 Советы для новичков

1. Начните с 10-15 карточек - не пытайтесь создать все сразу

2. Используйте темы - это поможет в дальнейшей фильтрации

3. Добавляйте объяснения - они помогают лучше запомнить материал

4. Регулярно повторяйте - лучше по 10 минут каждый день, чем 2 часа раз в неделю

❓ Частые вопросы новичков

В: Как удалить карточку?

О: Откройте ответ и найдите кнопку удаления.

В: Можно ли редактировать карточку?

О: Да, откройте ответ и нажмите "Редактировать".

В: Что значит "скрыть карточку"?

О: Это временно убирает карточку из общего списка, но не удаляет ее. Полезно для фокусировки на новых или сложных карточках.
