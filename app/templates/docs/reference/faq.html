В этом разделе собраны ответы на самые распространенные вопросы о HomeoRemedyTest.

📋 Общие вопросы

В: Для кого предназначено это приложение?

О: HomeoRemedyTest создано для:

  • Студентов-гомеопатов (для подготовки к экзаменам)
  • Преподавателей гомеопатии (для создания тестов)
  • Практикующих врачей-гомеопатов (для освежения знаний)
  • Всех, кто изучает гомеопатию (для самообучения)

В: На каких устройствах работает приложение?

О: Приложение работает на:

  • Любом устройстве с современным браузером (компьютер, планшет, телефон)
  • Рекомендуемые браузеры: Chrome, Firefox, Safari, Edge

В: Как добавить приложение на главный экран телефона?

О:

  • iPhone/iPad: В Safari → "Поделиться" → "На экран "Домой"
  • Android: В Chrome → три точки → "Добавить на главный экран"
  • После добавления: Приложение будет работать как обычное мобильное приложение

💾 Работа с данными

В: Как сделать резервную копию данных?

О:

  1. Перейдите в меню действий (три точки в правом верхнем углу)
  2. Выберите "Экспорт в Excel"
  3. Сохраните файл в надежном месте
  4. Рекомендуется делать резервные копии раз в неделю

В: Как восстановить данные из резервной копии?

О:

  1. Перейдите в меню действий
  2. Выберите "Импорт из Excel"
  3. Выберите файл с резервной копией
  4. Выберите режим "Заменить все"
  5. Подтвердите импорт

В: Что делать, если удалил карточку по ошибке?

О:

  1. Если у вас есть резервная копия - восстановите из нее
  2. Если нет - проверьте, может быть карточка просто скрыта
  3. Включите фильтр "Скрытые карточки" в боковой панели
  4. Найдите нужную карточку и нажмите "Показать"

В: Как перенести данные на другой компьютер?

О: Через экспорт/импорт:

  1. На старом компьютере: экспортируйте все карточки в Excel
  2. Перенесите файл на новый компьютер (email, флешка, облако)
  3. На новом компьютере: импортируйте файл в режиме "Заменить все"
  4. Проверьте, что все данные корректно отобразились

🔧 Использование приложения

В: Как создать новую карточку?

О:

  1. Нажмите на кнопку "+" в правом верхнем углу
  2. Заполните все поля формы
  3. Нажмите "Сохранить вопрос"
  4. Подробнее в разделе Работа с карточками

В: Как отредактировать существующую карточку?

О:

  • В режиме сетки: Нажмите на карточке кнопку "Редактировать"
  • В режиме стопки: Откройте ответ → нажмите "Редактировать"
  • Внесите изменения и сохраните

В: Как скрыть карточку?

О:

  1. Найдите нужную карточку
  2. Нажмите кнопку "Скрыть" (глаз с перечеркнутой линией)
  3. Карточка исчезнет из общего списка
  4. Чтобы вернуть - включите фильтр скрытых карточек и нажмите "Показать"

В: Как использовать фильтры?

О:

  1. В боковой панели выберите нужный фильтр:
    • Поиск - для текстового поиска
    • Темы - для фильтрации по категориям
    • Сложность - по уровню сложности
    • Версии - по тестам/экзаменам
  2. Нажмите на нужный вариант
  3. Подробнее в разделе Фильтры и поиск

В: В чем разница между режимами сетки и стопки?

О:

  • Режим сетки: Все карточки видны сразу, удобно для общего обзора и редактирования
  • Режим стопки: Одна карточка в фокусе, удобно для интенсивного обучения
  • Подробнее в разделе Режимы просмотра

В: Как экспортировать карточки в Excel?

О:

  1. Нажмите на меню действий (три точки в правом верхнем углу)
  2. Выберите "Экспорт в Excel"
  3. Файл скачается автоматически
  4. Подробнее в разделе Импорт и экспорт

В: Как импортировать карточки из Excel?

О:

  1. Подготовьте файл в нужном формате (.xlsx)
  2. Нажмите на меню действий
  3. Выберите "Импорт из Excel"
  4. Выберите файл и режим импорта
  5. Подробнее в разделе Импорт и экспорт

🐛 Проблемы и ошибки

В: Приложение зависает или работает медленно

О: Возможные причины и решения:

  1. Слишком много карточек (более 5000) - разбейте на несколько наборов
  2. Проблемы с браузером - попробуйте другой браузер или обновите текущий
  3. Нехватка памяти - закройте другие вкладки и программы
  4. Проблемы с интернетом - проверьте соединение (для онлайн версии)

В: Потерялись данные после обновления

О:

  1. Проверьте, может быть данные просто не загрузились - перезагрузите страницу
  2. Восстановите из резервной копии Excel
  3. Проверьте фильтры (может быть включен фильтр скрытых карточек)
  4. Проверьте, не используете ли вы другой аккаунт или устройство

В: Ошибка при импорте Excel файла

О:

  1. Проверьте формат файла (должен быть .xlsx или .xls)
  2. Проверьте, что есть обязательные колонки: "Вопрос" и "Ответ"
  3. Используйте предпросмотр для проверки формата
  4. Попробуйте открыть и сохранить файл заново в Excel
  5. Убедитесь, что файл не поврежден

В: Не работает поиск или фильтры

О:

  1. Проверьте, что введен текст поиска
  2. Проверьте, что карточки соответствуют критериям фильтра
  3. Очистите кэш браузера (для онлайн версии)
  4. Перезагрузите приложение
  5. Попробуйте другой браузер
