Карточки - это основа HomeoRemedyTest. В этом разделе вы узнаете все о создании, редактировании и организации карточек.

📝 Структура карточки

Каждая карточка содержит несколько полей:

Обязательные поля

1. Тема - категория карточки (например: Растения, Животные, Минералы)

  •   - Можно указать несколько тем через запятую: Растения, Жаропонижающие
  •   - Темы автоматически добавляются в фильтры

2. Вопрос - текст вопроса для самопроверки

  •   - Будьте конкретны: Какой препарат показан при...?
  •   - Избегайте слишком общих формулировок

3. Ответ - правильный ответ на вопрос

  •   - Кратко и по делу
  •   - Можно использовать ключевые слова

Дополнительные поля

4. Объяснение (необязательно) - подробное объяснение ответа

  •   - Почему именно этот ответ?
  •   - Дополнительная информация
  •    - Примеры из практики

5. Сложность - уровень сложности вопроса:

  •   - Легкий - базовые знания
  •   - Средний - требуют размышления
  •   - Сложный - специализированные вопросы

6. Версия (необязательно) - для группировки по тестам:

  •   - Экзамен 2026
  •   - Тест по Materia Medica
  •   - Промежуточный тест

7. Скрытый - флаг, скрывающий карточку из общего списка

  •   - Полезно для временного исключения хорошо изученных карточек

➕ Создание новой карточки

Через кнопку "+" (Добавить вопрос)

1. Нажмите на кнопку с плюсом в верхней панели

2. Заполните все поля формы

3. Нажмите "Сохранить вопрос"

Лучшие практики при создании:

Тема: Растения

Вопрос Каковы ключевые показания для Belladonna?

Ответ: Внезапное начало, высокая температура, покраснение, пульсирующая боль

Объяснение: Belladonna показана при состояниях с внезапным и бурным началом, часто сопровождающихся лихорадкой, покраснением кожи и пульсирующей болью. Характерно ухудшение от прикосновения и движения.

Сложность: Средний

✏️ Редактирование карточек

Как редактировать:

1. В режиме сетки: Откройте ответ → нажмите нажмите "Редактировать"

2. В режиме стопки: Откройте ответ → нажмите "Редактировать"

3. Внесите изменения

4. Сохраните

Что можно редактировать:

  • Исправить опечатки в вопросе или ответе
  • Добавить или уточнить объяснение
  • Изменить тему или сложность
  • Обновить версию теста

🗑️ Удаление карточек

Временное скрытие vs Удаление

Скрыть карточку:

  • Карточка не показывается в общем списке
  • Можно вернуть в любой момент
  • Идеально для карточек, которые вы уже хорошо знаете

Удалить карточку:

  • Карточка удаляется навсегда
  • Требуется подтверждение
  • Используйте осторожно!

Как удалить:

1. Откройте ответ → нажмите кнопку "Удалить"

2. Подтвердите действие

3. Карточка будет удалена безвозвратно

Совет: Перед удалением экспортируйте данные для резервной копии.

👁️ Управление видимостью карточек

Зачем скрывать карточки?

1. Фокус на новом материале - скройте уже изученное

2. Подготовка к экзамену - работайте только со сложными карточками

3. Повторение по темам - показывайте только определенные темы

Как скрыть/показать:

1. Найдите нужную карточку

2. Откройте ответ → нажмите кнопку "Скрыть" (она станет "Показать")

3. Чтобы показать скрытую карточку, нажмите "Показать"

Просмотр скрытых карточек:

1. В боковой панели найдите переключатель "Скрытые карточки"

2. Включите его

3. Теперь видны все карточки, включая скрытые

🏷️ Организация по темам

Лучшие практики работы с темами:

Несколько тем в одной карточке:

Тема: Растения, Жаропонижающие, Педиатрия

Стандартные темы для гомеопатии:

  • Растения - препараты растительного происхождения
  • Животные - препараты животного происхождения
  • Минералы - минеральные препараты
  • Нозоды - препараты из продуктов болезни
  • Саркоды - препараты из здоровых тканей
  • Полихресты - многогранные препараты

💡 Профессиональные советы

Для студентов:

  • Создавайте карточки сразу после лекции
  • Группируйте по темам семестра
  • Используйте версии для разных экзаменов

Для преподавателей:

  • Создавайте наборы карточек для студентов
  • Используйте разные уровни сложности
  • Экспортируйте в Excel для раздачи

Для практикующих врачей:

  • Создавайте карточки на основе сложных случаев
  • Добавляйте фотографии симптомов (через объяснения)
  • Группируйте по системам органов

Помните: качество карточек важнее их количества. 100 хорошо составленных карточек ценнее 1000 некачественных.
