HomeoRemedyTest предлагает два удобных режима просмотра карточек: Сетка и Стопка. Каждый режим предназначен для разных целей обучения.

🟦 Режим Сетки

Классический вид - все карточки отображаются в виде сетки.

Когда использовать режим сетки:

  • ✅ Общий обзор всех карточек
  • ✅ Быстрый поиск конкретной карточки
  • ✅ Редактирование и управление карточками
  • ✅ Работа с большим количеством карточек

Особенности режима сетки:

  • Многоколоночный вид - карточки расположены в несколько колонок
  • Пагинация - разбиение на страницы при большом количестве карточек

Навигация в режиме сетки:

1. Прокрутка - используйте колесико мыши или полосу прокрутки

2. Пагинация - внизу страницы для перехода между страницами

3. Кнопки прокрутки - справа внизу для быстрого перехода вверх/вниз

Пример использования:

Вы готовитесь к экзамену и хотите:

  • Увидеть все карточки по теме "Растения"
  • Быстро найти конкретный препарат

Решение: Используйте режим сетки с фильтром по теме.

🃏 Режим Стопки

Интерактивный режим - карточки отображаются по одной, как стопка карт.

Когда использовать режим стопки:

  • ✅ Интенсивное обучение и повторение
  • ✅ Подготовка к устному экзамену
  • ✅ Тренировка быстрого вспоминания
  • ✅ Фокус на одной карточке без отвлечений
  • ✅ Имитация экзаменационной ситуации

Особенности режима стопки:

  • Одна карточка в центре внимания
  • Анимированные переходы между карточками
  • Интерактивное управление - перетаскивание, стрелки
  • Счетчик прогресса - текущая позиция из общего количества

Управление в режиме стопки:

Способ 1: Перетаскивание мышью/пальцем

  • Потяните влево → предыдущая карточка
  • Потяните вправо → следующая карточка
  • Анимация показывает направление движения

Способ 3: Клавиатура

  • Стрелка влево или Page Up - предыдущая карточка
  • Стрелка вправо или Page Down - следующая карточка
  • Пробел - показать/скрыть ответ
  • Home - первая карточка
  • End - последняя карточка
  • Escape - при открытом ответе скрыть его

Способ 4: Свайп на мобильных

На смартфонах и планшетах используйте свайп влево/вправо.

Работа с ответами в режиме стопки:

1. Посмотрите на вопрос - попытайтесь вспомнить ответ

2. Нажмите "Показать ответ" - проверьте себя

3. Прочитайте объяснение (если есть) - углубите понимание

4. Нажмите "Скрыть ответ" - переходите к следующей карточке

Пример использования:

Вы повторяете материал перед экзаменом:

  • Включите режим стопки
  • Фильтруйте только сложные карточки
  • Пройдите всю стопку, пытаясь вспомнить ответы
  • Карточки, на которые ответили правильно, отмечайте как "изученные"
  • Повторите только ошибки

Решение: Режим стопки идеален для интенсивного повторения.

🔄 Переключение между режимами

Как переключиться:

1. Найдите переключатель в верхней панели

2. Две иконки:

  •   - 🟦 Квадратики - режим сетки
  •   - 🃏 Стопка карт - режим стопки

3. Нажмите на нужный режим

Что сохраняется при переключении:

  • ✅ Все фильтры (темы, сложность, поиск)
  • ✅ Скрытые карточки остаются скрытыми
  • ✅ Позиция в списке (в разумных пределах)

🧠 Какой режим когда использовать?

Для разных этапов обучения:

Этап 1: Создание карточек → Используйте режим сетки

  • Удобно видеть все созданные карточки
  • Легко находить дубликаты
  • Просто редактировать несколько карточек подряд

Этап 2: Первое изучение → Используйте режим стопки

  • Фокус на одном вопросе
  • Активное вспоминание ответов
  • Постепенное прохождение материала

Этап 3: Повторение → Чередуйте режимы

  • Режим стопки для интенсивного повторения
  • Режим сетки для поиска слабых мест

Этап 4: Подготовка к экзамену → Используйте режим стопки

  • Имитация экзаменационной ситуации
  • Тренировка скорости ответов
  • Фокус на сложных вопросах

Для разных типов материала:

Факты и определения → Режим стопки

  • Быстрое запоминание
  • Частое повторение

Сравнения и таблицы → Режим сетки

  • Нужно видеть несколько карточек одновременно
  • Сравнительный анализ

Клинические случаи → Режим стопки

  • Полное погружение в случай
  • Последовательное обдумывание

📱 Особенности на мобильных устройствах

Смартфоны:

  • Режим стопки - более удобен из-за ограниченного экрана
  • Свайпы - основной способ навигации
  • Вертикальная ориентация - оптимальна для чтения

Планшеты:

  • Оба режима работают хорошо
  • Режим сетки - можно видеть больше карточек
  • Горизонтальная ориентация - удобна для сравнения

Экспериментируйте с обоими режимами, чтобы найти оптимальный для вашего стиля обучения. Многие пользователи начинают с режима сетки для общего обзора, а затем переходят в режим стопки для интенсивного изучения.
