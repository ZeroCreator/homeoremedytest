# HomeoremedyTest

**Приложение для тестирования знаний по гомеопатии**

HomeoRemedyTest помогает студентам и практикующим гомеопатам эффективно готовиться к экзаменам и проверять свои знания.

___
## ✨ Возможности

- ✅ **Добавление карточек** с вопросами, ответами и объяснениями
- ✅ **Два режима просмотра**: классическая сетка и интерактивная стопка карточек
- ✅ **Умные фильтры** по темам, сложности и версиям
- ✅ **Поиск** по всем карточкам
- ✅ **Импорт/экспорт** в Excel для обмена вопросами
- ✅ **Синхронизация** с Яндекс.Диском для доступа с разных устройств

___
## 🚀 Быстрый старт

### Вариант 1: Локальная установка

```bash
# Клонируйте репозиторий
git clone https://github.com/zerocreator/HomeoRemedyTest.git

# Перейдите в папку проекта
cd HomeoRemedyTest

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python app.py
```
Откройте браузер и перейдите по адресу: http://localhost:5001

### Вариант 2: Онлайн версия

Посетите: https://homeoremedytest.vercel.app

## Локальный запуск документации

Вы можете запустить документацию локально для просмотра и редактирования:

```bash
# Установите mkdocs и необходимые расширения
pip install mkdocs mkdocs-material

# Запустите локальный сервер документации
mkdocs serve

# Откройте браузер по адресу: http://localhost:8000
```

## Сборка документации

Чтобы собрать документацию для публикации:

```bash
# Собрать HTML версию в папку site/
mkdocs build

# Опубликовать на GitHub Pages
mkdocs gh-deploy
```
