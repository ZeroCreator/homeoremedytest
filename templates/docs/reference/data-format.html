В этом разделе описаны требования к формату Excel файлов для импорта и экспорта карточек в HomeoRemedyTest.

📁 Структура Excel файла

Файл должен иметь следующие столбцы в указанном порядке:

Колонка Название Обязательно
A № (ID) Да
B Вопрос Да
C Ответ Да
D Объяснение Нет
E Тема Да
F Сложность Да
G Скрытый Да
H Версия Нет

📋 Подробное описание колонок

Колонка Описание Формат Пример Примечания
A (№) Уникальный номер карточки Число 1, 2, 3 При импорте: если 0 или пусто - будет назначен автоматически
B (Вопрос) Текст вопроса для самопроверки Текст "Какое средство показано при внезапной лихорадке?" Максимум 1000 символов
C (Ответ) Правильный ответ на вопрос Текст "Belladonna" Максимум 2000 символов
D (Объяснение) Подробное объяснение ответа Текст "Belladonna показана при состояниях с внезапным и бурным началом..." Поддерживает переносы строк (Alt+Enter в Excel)
E (Тема) Категория карточки Текст "Растения, Жаропонижающие" Несколько тем через запятую
F (Сложность) Уровень сложности вопроса Текст "Средний" Допустимые значения: "Легкий", "Средний", "Сложный" или "easy", "medium", "hard"
G (Скрытый) Видимость карточки Текст/Логическое "Нет" Допустимые значения: "Да" (скрыта) или "Нет" (видна)
H (Версия) Метка для группировки карточек Текст "Экзамен по Materia Medica" Любая произвольная метка

⚠️ Частые проблемы при работе с Excel

Проблема: "Файл не загружается"

Возможные причины:

  • Неправильный формат файла (требуется .xlsx или .xls)
  • Отсутствуют обязательные столбцы
  • Файл слишком большой (>50 MB)

Решение:

  • Сохраните файл в формате .xlsx
  • Проверьте наличие всех обязательных столбцов
  • Разделите большой файл на несколько частей

Проблема: "Неправильно отображаются русские буквы"

Возможные причины:

  • Неправильная кодировка файла
  • Проблемы с шрифтами в Excel

Решение:

  • Сохраните файл с кодировкой UTF-8
  • Используйте стандартные шрифты (Arial, Times New Roman)

Проблема: "Потеряны переносы строк"

Возможные причины:

  • В Excel не использовался Alt+Enter для переноса
  • Формат ячеек не позволяет перенос по словам

Решение:

  • Для переноса строк внутри ячейки используйте Alt+Enter
  • Установите для ячеек формат "Переносить текст"

💡 Советы по работе с Excel файлами

  1. Создавайте резервные копии перед массовым импортом
  2. Используйте предпросмотр перед импортом для проверки данных
  3. Разделяйте темы запятыми без пробелов: "Растения,Животные,Минералы"
  4. Экспортируйте регулярно для создания резервных копий
  5. Проверяйте сложность - используйте только допустимые значения

🔄 Миграция между устройствами

Для переноса данных между устройствами:

  1. На исходном устройстве: Экспортируйте все карточки в Excel
  2. Перенесите файл Excel на новое устройство (по email, облаку, флешке)
  3. На целевом устройстве: Импортируйте файл в режиме "Заменить все"
  4. Проверьте, что все данные корректно отображаются

Важно: Для корректной работы всегда используйте рекомендованный формат .xlsx с кодировкой UTF-8.
