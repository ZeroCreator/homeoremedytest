🔐 Хранение данных и система бэкапов

HomeoRemedyTest использует продвинутую систему хранения данных с поддержкой синхронизации и автоматического резервного копирования.

📂 Режимы хранения данных

Приложение поддерживает три режима работы с данными:

🏠 Локальный режим

Как работает: Данные хранятся только на вашем устройстве в файле test_cards.json

  • ✅ Не требует интернета
  • ✅ Максимальная скорость работы
  • ❌ Нет синхронизации между устройствами
  • ❌ Риск потери данных при сбое устройства

☁️ Режим Яндекс.Диск

Как работает: Данные хранятся только на Яндекс.Диске

  • ✅ Доступ с любого устройства
  • ✅ Автоматическая загрузка при запуске
  • ❌ Требует постоянного интернет-соединения
  • ❌ Медленнее локального режима

🤝 Гибридный режим (рекомендуется)

Как работает: Данные хранятся и локально, и на Яндекс.Диске

  • ✅ Быстрая работа с локальной копией
  • ✅ Контроль над синхронизацией
  • ✅ Работа без интернета (с локальной копией)
  • ✅ Ручная синхронизация по кнопке
  • ⏱️ Позволяет работать офлайн

🔄 Как работает гибридная синхронизация

Важно! В гибридном режиме синхронизация происходит только по вашему запросу:

🚀 Логика работы:

  1. Изменения сохраняются только локально - при добавлении, редактировании или удалении карточек
  2. Для отправки в облако - используйте кнопку "Синхронизировать на Яндекс.Диск"
  3. Для загрузки из облака - используйте кнопку "Загрузить с Яндекс.Диска"
  4. Автоматической синхронизации НЕТ - полный контроль за вами

🎯 Преимущества подхода:

  • Полный контроль - вы решаете, когда синхронизировать данные
  • Безопасность - случайные изменения не попадают в облако автоматически
  • Экономия трафика - данные отправляются только по вашему желанию
  • Работа без интернета - можно вносить изменения офлайн, а синхронизировать позже
  • Защита от ошибок - если вы ошиблись при редактировании, можно не синхронизировать

💾 Система бэкапов

Настройки бэкапов

Вы можете настроить поведение системы бэкапов через файл .env:

MAX_BACKUPS - максимальное количество хранимых бэкапов (по умолчанию 50).

  • При создании нового бэкапа самые старые автоматически удаляются
  • Значение 0 или отрицательное - без ограничений (не рекомендуется)
  • Рекомендуется: 20-30 для экономии места

BACKUP_ON_START - создание бэкапа при запуске приложения.

  • true - создает автоматический бэкап при каждом запуске
  • false (по умолчанию) - бэкапы создаются только вручную
  • Полезно для автоматической защиты данных

Пример настроек в файле .env:

MAX_BACKUPS=30
BACKUP_ON_START=true

Ручное создание бэкапов

Вы можете в любой момент создать резервную копию:

  1. Перейдите в раздел "Управление бэкапами"
  2. Нажмите "Создать бэкап"
  3. Укажите описание (необязательно)
  4. Выберите где сохранить:
    • 📁 Локально - только на вашем устройстве
    • ☁️ На Яндекс.Диске - в облаке
    • 🤝 Везде - и локально, и в облаке

Восстановление из бэкапа

Для восстановления данных:

  1. Откройте раздел "Управление бэкапами"
  2. Выберите нужный бэкап из списка
  3. Нажмите "Восстановить"
  4. Подтвердите операцию
  5. Выберите куда восстановить (локально, на Яндекс.Диске или везде)

Управление бэкапами

Вы можете:

  • 📋 Просматривать все бэкапы - локальные и с Яндекс.Диска
  • 📊 Сортировать по дате, размеру или количеству карточек
  • 🗑️ Удалять старые бэкапы для экономии места
  • 🔍 Просматривать информацию о каждом бэкапе
  • ⚙️ Настраивать лимиты через файл .env

⚠️ Устранение неполадок

Проблема: Бэкапы не создаются/не восстанавливаются

Решения:

  • Проверьте права доступа: У приложения должны быть права на запись в папку backups
  • Проверьте настройки Яндекс.Диска: Токен должен иметь права на запись
  • Проверьте наличие места: На диске должно быть достаточно свободного места
  • Проверьте настройки MAX_BACKUPS: Если 0, старые бэкапы не удаляются

💡 Рекомендации по использованию

  1. Используйте гибридный режим - это защитит ваши данные и даст контроль над синхронизацией
  2. Установите BACKUP_ON_START=true для автоматической защиты при каждом запуске
  3. Установите MAX_BACKUPS=30 - достаточно для восстановления и экономии места
  4. Создавайте бэкапы перед массовыми операциями (импорт, очистка)
  5. Храните хотя бы один бэкап на Яндекс.Диске - на случай потери устройства
  6. Периодически проверяйте состояние хранилища в разделе "Статус системы"

💡 Важно! В гибридном режиме изменения сохраняются только локально. Для синхронизации с Яндекс.Диском используйте кнопки в разделе "Статус системы".
