В этом разделе вы познакомитесь с основными функциями приложения, которые помогут вам эффективно изучать гомеопатию.

📊 Основные функции

1. Создание и редактирование карточек

  •   - Добавление новых вопросов через простую форму
  •   - Редактирование существующих карточек в один клик
  •   - Гибкая структура карточек с полями: вопрос, ответ, объяснение, тема, сложность, версия

2. Организация карточек

  •   - Автоматическая группировка по темам - система сама определяет все темы из добавленных карточек
  •   - Уровни сложности - отмечайте карточки как "легкие", "средние" или "сложные"
  •   - Версии тестов - группируйте карточки по тестам или экзаменам

3. Скрытие карточек

  •   - Временное скрытие карточек, которые вы уже хорошо знаете
  •   - Фокус на сложных темах - скрывайте легкие вопросы, чтобы сосредоточиться на сложных

🎮 Режимы работы

Режим "Сетка"

Просмотр всех карточек в виде удобной сетки. Идеально для:

  • Общего обзора всех вопросов
  • Быстрого поиска конкретной карточки
  • Редактирования и управления карточками

Режим "Стопка"

Интерактивный режим для обучения. Особенности:

  • Перетаскивание карточек влево/вправо для навигации
  • Анимированные переходы между карточками
  • Скрытие ответа до нажатия кнопки
  • Управление с клавиатуры - используйте стрелки для навигации

🔧 Инструменты

Фильтрация и поиск

  • Быстрый поиск по тексту вопросов и ответов
  • Фильтры по темам - кликните на тему в сайдбаре
  • Фильтры по сложности - выберите только сложные или только легкие вопросы>
  • Фильтр по версиям - сгруппируйте вопросы по конкретному тесту

Импорт и экспорт

  • Экспорт в Excel - скачайте все карточки в формате Excel
  • Импорт из Excel - загрузите вопросы из существующих файлов
  • Предпросмотр перед импортом - увидите, какие данные будут загружены
  • Два режима импорта: добавление к существующим или полная замена

Синхронизация

  • Локальное хранение - данные хранятся на вашем компьютере
  • Яндекс.Диск (опционально) - синхронизация между устройствами
  • Автоматическое резервное копирование

📱 Удобство использования

Адаптивный дизайн

Приложение отлично работает на:

  • Компьютерах и ноутбуках
  • Планшетах
  • Смартфонах

Быстрая навигация

  • Боковая панель с фильтрами всегда под рукой
  • Кнопки быстрой прокрутки вверх/вниз

Безопасность

  • Локальное хранение - ваши данные остаются у вас

💡 Советы по использованию функций

1. Используйте несколько тем в одной карточке - разделяйте темы запятой

2. Добавляйте объяснения - это поможет лучше запомнить материал

3. Регулярно экспортируйте данные - создавайте резервные копии

4. Используйте режим стопки для повторения - это самый эффективный способ запоминания

Пример эффективного использования: создайте набор карточек по одной теме, отметьте сложность, регулярно повторяйте в режиме стопки, а перед экзаменом экспортируйте в Excel для печати.
