📤 Экспорт в Excel

HomeoRemedyTest позволяет легко экспортировать карточки в Excel для создания резервных копий, печати или обмена с коллегами.

Зачем экспортировать?

  • Резервное копирование - на случай проблем с приложением
  • Печать карточек - для занятий без компьютера
  • Обмен с коллегами - отправьте файл по почте
  • Анализ в Excel - сортировка, фильтрация, статистика
  • Перенос на другое устройство

Как экспортировать:

  1. Нажмите на меню действий (три точки в верхней панели)
  2. Выберите "Экспорт в Excel"
  3. Файл скачается автоматически в формате .xlsx

Формат экспортируемого файла:

Колонка Описание Пример
№ ID карточки 1
Вопрос Текст вопроса Какое средство при сухости во рту?
Ответ Правильный ответ Bryonia
Объяснение Подробное объяснение Показана при сухих слизистых...
Тема Категория карточки Растения
Сложность Уровень сложности Легкий
Скрытый Видимость карточки Нет
Версия Версия теста Экзамен 2026

Особенности экспорта:

  • Поддержка русского языка - кодировка UTF-8
  • Сохранение форматирования - переносы строк остаются
  • Автоматическая ширина колонок - удобно для чтения

Пример использования экспорта:

Сценарий 1: Печать для занятий в транспорте

  1. Экспортируйте карточки
  2. Откройте в Excel
  3. Настройте печать (можно по 4 карточки на страницу)
  4. Распечатайте и вырежьте

Сценарий 2: Статистический анализ

  1. Экспортируйте карточки
  2. Используйте сводные таблицы Excel
  3. Проанализируйте распределение по темам и сложности
  4. Определите слабые места

Сценарий 3: Совместная работа

  1. Создайте набор карточки
  2. Экспортируйте
  3. Отправьте коллегам
  4. Они импортируют к себе

📥 Импорт из Excel

Быстро добавляйте карточки из существующих файлов или восстанавливайте из резервной копии.

Поддерживаемые форматы:

  • .xlsx (Excel 2007+)
  • .xls (старый формат Excel)

Требования к файлу:

  1. Обязательные колонки: Вопрос, Ответ
  2. Опциональные колонки: Объяснение, Тема, Сложность, Скрытый, Версия
  3. Первая строка - заголовки колонок
  4. Кодировка - UTF-8 или Windows-1251

Как импортировать:

  1. Нажмите на меню действий (три точки)
  2. Выберите "Импорт из Excel"
  3. Нажмите "Выбрать файл"
  4. Выберите Excel файл на вашем компьютере
  5. Выберите режим импорта:
    • Добавить к существующим - новые карточки добавятся к текущим
    • Заменить все - все текущие карточки будут заменены новыми
  6. Нажмите "Импортировать"

Предпросмотр перед импортом:

Перед окончательным импортом вы можете:

  1. Увидеть предпросмотр - первые строки файла
  2. Проверить соответствие колонок
  3. Оценить количество новых карточек
  4. Отменить импорт если что-то не так

Режимы импорта:

Режим 1: "Добавить к существующим"

Используйте, когда хотите:

  • Добавить новые карточки к имеющимся
  • Объединить несколько наборов карточек
  • Восстановить из резервной копии без потери текущих данных

Особенности:

  • Проверка на дубликаты (карточки с одинаковыми вопросами не добавляются)
  • Сохранение текущих ID карточек
  • Новым карточкам назначаются следующие ID

Режим 2: "Заменить все"

Используйте, когда хотите:

  • Полностью заменить текущие карточки новыми
  • Начать с чистого листа
  • Восстановить конкретную версию резервной копии

Важно! Все текущие карточки будут удалены.

Обработка дубликатов:

При импорте в режиме "Добавить к существующим" система проверяет дубликаты:

Как определяется дубликат:

  1. Нормализуется текст вопроса (убираются пробелы, знаки препинания, приводится к нижнему регистру)
  2. Сравнивается с существующими вопросами
  3. Если найден дубликат - карточка не добавляется

Пример:

  • Существующий вопрос: "Что такое гомеопатия?"
  • Импортируемый вопрос: "Что такое гомеопатия?"
  • Результат: Дубликат, не добавляется

🔄 Синхронизация через импорт/экспорт

Сценарий: Работа на нескольких компьютерах

  1. На компьютере 1: Экспортируйте карточки
  2. Перенесите файл на компьютер 2 (флешка, облако, почта)
  3. На компьютере 2: Импортируйте файл в режиме "Заменить все"
  4. Повторите при необходимости в обратном направлении

Сценарий: Совместная работа над набором карточек

  1. Создайте базовый набор и экспортируйте
  2. Разошлите коллегам
  3. Каждый дополняет набор на своем компьютере
  4. Собираете все варианты и объединяете через импорт

📁 Подготовка файла для импорта

Создание файла с нуля:

  1. Откройте Excel
  2. Создайте заголовки: Вопрос, Ответ, Объяснение, Тема, Сложность, Скрытый, Версия
  3. Заполните данные
  4. Сохраните как .xlsx

Советы по подготовке файла:

  • Используйте кавычки если в тексте есть запятые
  • Для переносов строк внутри ячейки используйте Alt+Enter
  • Сложность пишите точно: Легкий, Средний или Сложный
  • Скрытый: Да/Нет или True/False

⚠️ Решение проблем при импорте/экспорте

Проблема: "Неверный формат файла"

Решение:

  • Убедитесь, что файл в формате .xlsx или .xls
  • Попробуйте открыть файл в Excel и сохранить заново
  • Проверьте, что первая строка содержит заголовки

Проблема: "Отсутствуют обязательные колонки"

Решение:

  • Проверьте, что есть колонки "Вопрос" и "Ответ"
  • Заголовки должны быть именно так написаны
  • Используйте предпросмотр для проверки

🔒 Безопасность при импорте/экспорте

Рекомендации:

  • Регулярно экспортируйте резервные копии
  • Храните резервные копии в разных местах
  • Перед импортом "Заменить все" убедитесь, что у вас есть резервная копия текущих данных
  • Проверяйте файлы от неизвестных источников

Частота резервного копирования:

  • Еженедельно - полный экспорт
  • После добавления важных карточек - дополнительный экспорт
  • Перед крупными изменениями - обязательно сделайте экспорт

💡 Практические примеры

Пример 1: Преподаватель создает тест для студентов

  1. Создает 50 вопросов в Excel
  2. Экспортирует файл
  3. Рассылает студентам
  4. Студенты импортируют к себе

Пример 2: Студент готовится к экзамену

  1. Экспортирует все свои карточки
  2. Распечатывает сложные вопросы
  3. Занимается с распечаткой в транспорте
  4. После изучения - обновляет сложность в Excel и импортирует обратно

Пример 3: Групповой проект

  1. Каждый участник создает свою часть карточек
  2. Экспортирует в отдельный файл
  3. Ответственный собирает все файлы
  4. Объединяет в один и рассылает финальную версию

Импорт и экспорт - это мощные инструменты для работы с данными. Используйте их для создания резервных копий, обмена знаниями и эффективной организации учебного процесса.
