Умные фильтры и поиск в HomeoRemedyTest помогут вам быстро находить нужные карточки и эффективно организовывать процесс обучения.

🔍 Быстрый поиск

Поиск по всем полям карточек: вопросу, ответу, объяснению.

Как использовать поиск:

1. Найдите поле поиска в боковой панели

2. Введите ключевое слово (например: "лихорадка")

3. Результаты появятся автоматически (поиск работает в реальном времени)

Особенности поиска:

  • Нечувствителен к регистру - "Lycopodium" и "lycopodium" найдут одно и то же
  • Поиск по части слова - "гомео" найдет "гомеопатия", "гомеопатический"
  • Автоматическое обновление - результаты обновляются при вводе
  • Подсветка совпадений - найденные слова выделяются в карточках

Примеры поисковых запросов:

  • сухость - все карточки, где встречается это слово
  • жар холод - карточки, содержащие оба слова
  • -детский - исключить карточки со словом "детский"

🏷️ Фильтр по темам

Основной способ организации карточек.

Автоматическое извлечение тем:

Система сама определяет все темы из ваших карточек:

1. Если вы создали карточку с темой "Растения, Жаропонижающие"

2. В фильтрах появятся обе темы: "Растения" и "Жаропонижающие"

Как использовать фильтр по темам:

1. Откройте раздел "Темы" в боковой панели

2. Вы увидите список всех тем из ваших карточек

3. Рядом с каждой темой - количество карточек по этой теме

4. Нажмите на тему - отобразятся только карточки этой темы

Особенности:

  • Несколько тем в одной карточке - карточка появится при фильтрации по любой из своих тем
  • Автоматическая сортировка - темы сортируются по алфавиту

Пример использования:

У вас есть карточки:

Тема: "Растения, Жаропонижающие"

Тема: "Животные, Жаропонижающие"

Тема: "Растения, Противовоспалительные"

При фильтрации по теме "Жаропонижающие"

вы увидите карточки 1 и 2.

⚡ Фильтр по сложности

Фокусируйтесь на нужном уровне сложности.

Три уровня сложности:

1. Легкий - базовые знания, определения, факты

2. Средний - требуют размышления, сравнения

3. Сложный - специализированные, комплексные вопросы

Как использовать:

1. Откройте раздел "Сложность" в боковой панели

2. Выберите нужный уровень (или "Все уровни")

3. Карточки отфильтруются по выбранной сложности

Стратегии использования:

Для начинающих:

1. Начните с фильтра "Легкие"

2. Освойте базовые карточки

3. Добавьте "Средние"

4. Переходите к "Сложным" постепенно

Для повторения:

1. Отфильтруйте "Сложные" карточки

2. Сосредоточьтесь на них

3. По мере изучения меняйте сложность на "Средние"

Для экзамена:

1. Используйте все уровни

2. Но уделяйте больше времени сложным карточкам

🏗️ Фильтр по версиям

Группируйте карточки по тестам, экзаменам или курсам.

Что такое версии?

Версия - это метка для группировки карточек:

  • Экзамен 2026
  • Тест по Materia Medica
  • Курс для начинающих
  • Промежуточный тест 1

Как использовать:

1. При создании карточки укажите версию в соответствующем поле

2. В боковой панели откройте раздел "Версии"

3. Вы увидите список всех версий

4. Нажмите на версию - отобразятся все карточки этой версии

Полезные сценарии:

Для студентов:

Версия: "Экзамен по Основам гомеопатии"

Включает: все карточки для подготовки к конкретному экзамену

Для преподавателей:

Версия: "Тест для группы А"

Версия: "Тест для группы Б"

Разные наборы для разных групп студентов

Для самообучения:

Версия: "Неделя 1 - Введение"

Версия: "Неделя 2 - Растения"

Версия: "Неделя 3 - Животные"

Постепенное изучение по неделям

👁️ Фильтр скрытых карточек

Управляйте видимостью карточек.

Что такое скрытые карточки?

Карточки, которые временно не показываются в общем списке. Они не удалены, просто скрыты.

Зачем скрывать карточки?

1. Сфокусироваться на новом - скрыть уже изученное

2. Работать над ошибками - скрыть правильные ответы

3. Создать индивидуальную программу - скрыть неактуальное

4. Подготовиться к экзамену - показать только сложное

Как скрыть/показать карточку:

1. Найдите карточку

2. Нажмите кнопку "Скрыть" (она появится при наведении)

3. Карточка исчезнет из общего списка

4. Чтобы вернуть - включите фильтр скрытых карточек и нажмите "Показать"

Как просмотреть скрытые карточки:

1. В боковой панели найдите переключатель "Скрытые карточки"

2. Включите его

3. Теперь видны все карточки, включая скрытые

🎯 Комбинирование фильтров

Мощный инструмент для точного поиска.

Как комбинировать:

Вы можете одновременно применять несколько фильтров:

  • Тема + Сложность + Поиск
  • Версия + Скрытые карточки
  • Любые другие комбинации

Примеры комбинаций:

Пример 1: Подготовка к экзамену

Тема: "Растения"

Сложность: "Сложные"

Версия: "Экзамен 2026"

Результат: Сложные карточки по растениям для экзамена 2026

Пример 2: Повторение слабых мест

Поиск: "дифференциальная диагностика"

Сложность: "Средние" и "Сложные"

Скрытые карточки: Показаны

Результат: Все карточки по дифференциальной диагностике средней и высокой сложности, включая скрытые

Пример 3: Быстрое повторение

Тема: "Растения" или "Животные"

Сложность: "Легкие"

Результат: Легкие карточки по растениям и животным для быстрого повторения

Логика комбинирования:

  • Фильтры по теме, сложности, версии - работают как И (AND)
  • Поиск по нескольким словам - работает как ИЛИ (OR) по умолчанию
  • Можно комбинировать любые фильтры

📊 Статистика фильтров

Что показывает статистика:

  • Общее количество карточек
  • Количество по темам (в развернутом виде)
  • Количество по сложности
  • Количество скрытых карточек
  • Прогресс по версиям

Как использовать статистику:

1. Оцените объем - сколько карточек по каждой теме

2. Определите слабые места - где мало карточек или много сложных

3. Планируйте время - исходя из количества карточек

4. Отслеживайте прогресс - скрытые карточки = изученные

⚙️ Сохранение фильтров

Что сохраняется:

  • Текущие фильтры сохраняются в URL
  • Вы можете сохранить ссылку с фильтрами
  • При обновлении страницы фильтры сохраняются

Как поделиться фильтром:

1. Настройте нужные фильтры

2. Скопируйте URL из адресной строки

3. Отправьте ссылку

4. При переходе по ссылке откроются те же фильтры

Пример URL с фильтрами:

http://ваш-сайт/?theme=Растения&difficulty=hard&search=лихорадка

Используйте фильтры как инструмент для создания индивидуальной программы обучения. Хорошо настроенные фильтры могут ускорить ваше обучение в несколько раз!
