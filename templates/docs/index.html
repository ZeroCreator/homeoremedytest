Полное руководство по работе с HomeoRemedyTest

HomeoRemedyTest - это простое и удобное приложение для создания, изучения и тестирования карточек по гомеопатии. Оно поможет вам эффективно готовиться к экзаменам, проверять свои знания и систематизировать учебные материалы.

🎯 Кому подойдет это приложение?

  • Студентам-гомеопатам - для подготовки к экзаменам и закрепления материала
  • Преподавателям - для создания тестовых заданий и проверки знаний студентов
  • Практикующим врачам - для быстрого освежения знаний и подготовки к аттестациям
  • Всем, кто изучает гомеопатию - для систематического обучения и самопроверки

✨ Основные возможности

📝 Создание карточек

Легко добавляйте вопросы с ответами, объяснениями и тематической разметкой.

🔍 Умные фильтры

Фильтруйте карточки по:

  • Темам (Растения, Животные, Минералы и др.)
  • Уровню сложности (легкий, средний, сложный)
  • Версиям тестов
  • Поиску по тексту

📱 Два режима просмотра

  • Режим сетки - просмотр всех карточек в виде удобной сетки
  • Режим стопки - интерактивный режим для обучения с возможностью перетаскивания карточек

📤 Импорт/экспорт

  • Экспортируйте карточки в Excel для печати или обмена
  • Импортируйте вопросы из Excel файлов
  • Синхронизируйте данные между устройствами через Яндекс.Диск

🔄 Синхронизация и бэкапы

Продвинутая система хранения данных:

  • Гибридное хранение - локально и в облаке (Яндекс.Диск)
  • Автоматическая синхронизация между устройствами
  • Резервное копирование с восстановлением из любой точки
  • Защита данных - даже при потере устройства ваши карточки в безопасности

💡 Советы для новичков

1. Начните с малого - добавьте 10-15 карточек по одной теме

2. Используйте теги - правильно размечайте темы для удобной фильтрации

3. Регулярно повторяйте - используйте режим стопки для ежедневного повторения

4. Экспортируйте для печати - распечатайте карточки для занятий без компьютера
